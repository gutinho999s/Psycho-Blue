
# 🔵 Psycho Blue

**Psycho Blue** é um projeto de plataforma de vídeos curtos inspirado no TikTok, com visual moderno, tema azul e interface adaptada para celulares e computadores.

## ✨ Funcionalidades

- 🎬 Feed com vídeos de demonstração.
- ❤️ Sistema de curtidas.
- 💬 Comentários.
- 🔗 Compartilhamento de vídeos.
- 👤 Botão para seguir criadores.
- 🔍 Pesquisa por vídeos, legendas e criadores.
- 🧭 Seções "Para você", "Seguindo" e "Descobrir".
- 📤 Seleção e pré-visualização de vídeos locais.
- 📱 Design responsivo.
- 🌌 Interface escura com detalhes em azul neon.

## 🛠️ Tecnologias utilizadas

- HTML5 — estrutura da página.
- CSS3 — estilos, animações e responsividade.
- JavaScript — funcionalidades e interações.

## 🚀 Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.
4. Conecte-se à internet para carregar os vídeos de demonstração.

## 🌐 Como publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie os arquivos do projeto.
3. Entre em **Settings → Pages**.
4. Em Build and deployment, selecione a branch principal.
5. Escolha a pasta `/root` ou `/ (root)`, conforme a opção apresentada.
6. Salve e aguarde a publicação.

## ⚠️ Limitações da versão atual

Esta versão é um protótipo front-end.

- Os vídeos publicados pelo formulário são carregados localmente no navegador.
- Curtidas e comentários não são salvos em um banco de dados.
- Não existe cadastro ou login real.
- Não há armazenamento de vídeos na nuvem.
- Os vídeos de demonstração dependem de links externos.

Para transformar o projeto em uma plataforma completa, será necessário implementar um backend, autenticação de usuários, banco de dados e armazenamento de vídeos.
